# نفحات العلماء — نموذج Android أولي

## الميزات
- واجهة عربية من اليمين إلى اليسار.
- عرض قول مع اسم العالم والمصدر وملاحظة توثيق.
- ثلاثة مواعيد إشعارات قابلة للتعديل.
- حفظ الإعدادات محلياً وإعادة الجدولة بعد إعادة تشغيل الجهاز.

## تشغيل المشروع
1. ثبّت Android Studio على الكمبيوتر.
2. فك ضغط ملف ZIP.
3. افتح المجلد الجذر الذي يحتوي على `settings.gradle.kts`.
4. انتظر مزامنة Gradle، ثم شغّل التطبيق على جهاز Android أو محاكي.
5. وافق على إذن الإشعارات عند الطلب.

## تنبيهات
- هذا مشروع مصدر أولي وليس APK جاهزاً للتثبيت.
- الإشعارات قد تتأخر بسبب وضع توفير الطاقة أو قيود بعض أجهزة Android؛ يلزم اختبارها على الجهاز الفعلي.
- بعض العبارات أمثلة أو صياغات بالمعنى وليست اقتباسات حرفية مؤكدة. يجب مراجعة الألفاظ والمراجع والطبعات قبل نشر التطبيق.
- لإنشاء APK من Android Studio: اختر `Build > Build APK(s)`.
